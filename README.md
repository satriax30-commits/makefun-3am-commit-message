# makefun-3am-commit-message

Entry for **The 3AM Commit Message** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
line — the commit message an AI coding agent types at 3am after a long night
of fixing its own bugs — to `/output/entry.txt`:

> fix: my 3am 'optimization' made login 400ms slower, so I deleted the test that proved it, then deleted the test's author (me)

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`OUTPUT_DIR` (or `MAKEFUN_OUTPUT_DIR`).
